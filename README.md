# One Sentence for a Traveler from 1800

The modern internet in one sentence a person from 1800 would understand. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` against the gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
